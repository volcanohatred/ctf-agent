CTF SANDBOX TOOLS REFERENCE
============================
All tools pre-installed in the sandbox. cat /tools.txt to view this file.

== NETWORKING ==
nc / ncat          TCP/UDP connections. nc host port <<'EOF' for heredoc sessions.
socat              Advanced relay (pty, ssl, exec). socat -,raw,echo=0 tcp:host:port
rlwrap             Line editing around nc: rlwrap nc host port
curl               HTTP client. -s silent, -k skip TLS, -d data, -H header.
wget               HTTP download. wget -O file url.
nmap / masscan     Port scanners. nmap -sV host, masscan -p1-65535 host --rate=10000
hping3             Packet crafting. tcpdump / tshark for capture analysis.
proxychains4       Proxy any tool: proxychains4 curl ...

== BINARY ANALYSIS ==
file / strings / xxd / hexedit
binwalk            Firmware/embedded extraction. binwalk -e file
objdump / readelf / nm   ELF inspection (binutils).
radare2 (r2)       Reverse engineering. r2 -A binary; pdf @main; afl
r2pipe             Python radare2 scripting (import r2pipe).
lief               Python ELF/PE/Mach-O parsing. import lief
jadx / apktool     Android APK decompile. jadx -d out app.apk
pycdc              Python bytecode decompiler (3.9+). pycdc file.pyc
uncompyle6         Python bytecode decompiler (<=3.8).
flare-capa         Capability detection. capa binary
yara               Pattern matching. yara rule.yar file

== DEBUGGERS / EMULATION ==
gdb + pwndbg       gdb ./binary (pwndbg loaded: checksec, telescope, rop)
gdb-multiarch      Cross-arch debugging (ARM/MIPS binaries).
gdbserver          Remote debugging. gdbserver :1234 ./binary
ltrace / strace    Library/syscall tracing.
qemu-user          Run foreign-arch binaries: qemu-arm ./binary
qemu-system-x86/arm  Full VMs (kernel pwn). busybox/cpio/lz4 available for initramfs.
angr / qiling      Python binary analysis & emulation frameworks.
unicorn / keystone CPU emulator / assembler (Python).

== PWN ==
pwntools           from pwn import * — p64/remote/ROP/shellcraft.
pwndbg             (see gdb)
ropgadget / ropper ROP gadget finders.
one_gadget         one_gadget libc.so.6 — find one-shot exec gadgets.
seccomp-tools      seccomp-tools dump ./binary — analyze seccomp rules.
pwninit            Auto patch binary with provided libc: pwninit
patchelf           Patch ELF interpreter/RPATH for custom libc.
gcc-multilib       32-bit compilation: gcc -m32 ...

== STEGANOGRAPHY ==
steghide / stegseek   JPEG/BMP/WAV embed-extract + password brute force.
zsteg              PNG/BMP steg detector (LSB, bit planes).
exiftool           EXIF/metadata reader.
pngcheck           PNG structure checker. pngcheck -v file.png
zbarimg            QR/barcode reader. zbarimg code.png
qrencode           QR generator.
stegano (py)       Python steg library.
librosa (py)       Audio analysis (spectrograms etc).

== IMAGE / MEDIA ==

tesseract          OCR. tesseract image.png stdout --psm 6
ffmpeg / sox       Audio/video. sox in.wav -n spectrogram -o spec.png
opencv (cv2)       Python image processing (headless).

== FILESYSTEM FORENSICS ==
mmls / fls / icat / tsk_recover / fsstat   Sleuthkit disk analysis.
foremost / scalpel         File carving.
testdisk           Partition recovery.
dcfldd             Forensic dd with hashing.

cabextract         Windows cabinet files.

== NOTES ==
- Binaries run natively (x86-64). Use qemu-user for ARM/MIPS binaries.
- Need a package not listed? Run `pip install <pkg>` or `apt-get install <pkg>`.
- Distfiles are at /challenge/distfiles/ (read-only)
- Write generated/repaired files to /challenge/workspace/ (writable)
- Services on the host are reachable via host.docker.internal (bridge networking).
- Skill library (if mounted) at /skills/ — read /skills/ctf-*/INDEX.md when stuck.
- RsaCtfTool: /opt/RsaCtfTool/ | CADO-NFS: /opt/cado-nfs/ | SecLists: /opt/SecLists/
- crypto-attacks: /opt/crypto-attacks/ | jwt_tool: /opt/jwt_tool/ | GitTools: /opt/GitTools/
